# Cygnus

Η τελευταία έκδοση της σελίδας, έτοιμη για GitHub Pages.
HTML, CSS και JavaScript. Δεν απαιτούνται εγκατάσταση, npm ή build.

## Ανέβασμα

1. Αποσυμπίεσε το ZIP στον υπολογιστή σου.
2. Δημιούργησε ένα repository στο GitHub, για παράδειγμα cygnus.
3. Από Add file > Upload files ανέβασε όλα τα περιεχόμενα του ZIP.
   Το index.html πρέπει να βρίσκεται στη ρίζα του repository.
   Μην ανεβάσεις το ίδιο το ZIP και μην βάλεις τα αρχεία σε επιπλέον φάκελο.
4. Πάτησε Commit changes.
5. Άνοιξε Settings > Pages.
6. Στο Source επίλεξε Deploy from a branch.
7. Επίλεξε main και /(root), έπειτα Save.
8. Όταν ολοκληρωθεί η δημοσίευση, το GitHub θα εμφανίσει τη διεύθυνση.

## Αρχεία

index.html: Cygnus
solutions.html: Solutions
contact.html: Contact
style.css: εμφάνιση και responsive σχεδίαση
app.js: γραφικά, αλληλεπιδράσεις και πλοήγηση
mark.svg: σήμα
land.json: γεωγραφικά δεδομένα
navier-stokes.svg: διανυσματικό γραφικό
.nojekyll: απευθείας δημοσίευση στατικών αρχείων

Για τοπική δοκιμή χρησιμοποίησε έναν απλό HTTP server ή Live Server.
Η πλοήγηση κάνει fetch τις άλλες σελίδες, οπότε το διπλό κλικ στο
index.html δεν αποτελεί πλήρη δοκιμή της ιστοσελίδας.
