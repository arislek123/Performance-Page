# Cygnus · GitHub Pages

Η τελευταία έκδοση της ιστοσελίδας, έτοιμη για GitHub Pages.

## Ανέβασμα

1. Αποσυμπίεσε το ZIP.
2. Ανέβασε όλα τα περιεχόμενα στο repository σου. Το index.html πρέπει να βρίσκεται στη ρίζα του repository, όχι μέσα σε υποφάκελο. Ανέβασε και όλες τις εικόνες και το land.json.
3. Άνοιξε Settings → Pages.
4. Επίλεξε Deploy from a branch, branch main και φάκελο /(root), έπειτα Save.
5. Το GitHub θα εμφανίσει το link της σελίδας μόλις ολοκληρωθεί η δημοσίευση.

Δεν απαιτείται npm ή διαδικασία build. Περιλαμβάνονται οι σελίδες Company, Solutions και Contact, μαζί με τα animations και τα απαραίτητα αρχεία.

Για τοπική προεπισκόπηση χρησιμοποίησε HTTP server, για παράδειγμα την επέκταση Live Server. Το απλό διπλό κλικ στο index.html δεν αρκεί για όλες τις λειτουργίες πλοήγησης.
